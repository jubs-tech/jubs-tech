## Sobre mim 🪻

Tenho 24 anos e me interesso por tecnologia desde criança. Trabalhei com logística e hoje estou em transição de carreira para o desenvolvimento. Curso **Inteligência Artificial** e também faço um **técnico em Desenvolvimento de Sistemas**. Entre os trabalhos da faculdade e as ideias que quero testar por conta própria, estou criando minhas primeiras aplicações web e ferramentas de análise de dados.

Com **Python**, gosto de criar pequenas automações para o dia a dia, como organizar arquivos ou juntar dados de várias planilhas. Uso **SQL** para consultar dados e estou aprendendo a montar dashboards com **pandas** e **Streamlit**. No front-end, uma das partes de que mais gosto é dar identidade própria a um site ou aplicativo: escolher as cores, a tipografia e os detalhes da navegação.

### 🕹️ [Clube Pixel](https://github.com/jubs-tech/projeto-academico-clube-pixel) · 🚧 Em desenvolvimento

Meu primeiro projeto acadêmico: um clube de estudos com visual inspirado em pixel art, criado na disciplina de **Desenvolvimento Web para IA**.

**Já funciona:**

- **Nubi**, a atendente virtual do clube, que responde a perguntas pelo chat

**Futuras aplicações:**

- Sistema de login
- Disponibilização do material

**Stack:** HTML, CSS e JavaScript na interface · Node.js com Express no servidor · API do Google Gemini no chat
